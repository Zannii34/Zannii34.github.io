Django Task Manager

A GitHub Pages-friendly showcase adapted from Django task-list coursework, demonstrating authentication and model-backed CRUD concepts.

PythonDjangoAuthenticationCRUDModels
Open DemoView CodeAll Projects

The problem

The original Django application depends on a Python server and database, which cannot run directly on GitHub Pages.

My solution

I recreated the user-facing task workflow in JavaScript/localStorage while documenting the original Django architecture: browser → views → model → database.

Key features

  • Task creation, completion and deletion
  • Open/completed filters and search
  • Priority metadata
  • Architecture display for Django views/models
  • Persistent static demo for portfolio review

Challenge / technical decision

The key challenge was demonstrating backend concepts honestly without pretending a static GitHub Pages page is running Django.

What I learned

This helped me separate presentation from server architecture and communicate backend design clearly to reviewers.
