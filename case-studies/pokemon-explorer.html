Pokémon Explorer & Team Builder

A JavaScript application that consumes PokéAPI data and turns it into a searchable, filterable explorer with a persistent team builder.

JavaScriptREST APIPokéAPILocal Storage
Open DemoAll Projects

The problem

API data can quickly become difficult to browse. The goal was to make a larger Pokémon dataset easy to search, filter, sort and use interactively.

My solution

The app loads Pokémon details, normalizes the data into a simple client-side model and renders cards that respond to search, type and sorting controls.

Key features

  • Loads Pokémon data from PokéAPI
  • Search by name or Pokédex number
  • Filter by type and sort results
  • Random discovery button
  • Build and persist a six-Pokémon team

Challenge / technical decision

The app performs multiple API requests to build richer cards, so I added clear status messages and graceful network-error feedback.

My role

I designed and developed the front-end experience, PokéAPI integration, normalized client-side data, filtering, sorting and persistent team state.

What I learned

I improved my async JavaScript, DOM rendering, API handling and client-side state management skills.
