Tic-Tac-Toe Minimax AI

A playable browser adaptation of minimax-based adversarial search work, designed to make the underlying AI concept easy to test.

The problem

Algorithm coursework is difficult to evaluate from a repository alone, so the goal was to make the minimax concept directly interactive.

My solution

I adapted the game logic into a browser demo where the AI evaluates future game states and selects an optimal move.

Key features

  • Playable human-vs-AI board
  • Minimax decision making
  • Win/draw detection
  • Reset/replay workflow
  • Immediate browser demo

Challenge / technical decision

The AI needs to remain unbeatable while keeping the browser interaction responsive and understandable.

What I learned

The project reinforced recursive reasoning, game-state evaluation and translating algorithmic logic into an interactive interface.
