The problem

A useful task manager needs more than adding and deleting text; it should help users find, prioritize and complete work without losing data after refresh.

My solution

I built a client-side CRUD workflow backed by localStorage, with filtering and task metadata while keeping the interface fast and simple.

Key features

  • Add, complete and delete tasks
  • Categories and priorities
  • Due dates
  • Search and filtering
  • Persistent browser storage

Challenge / technical decision

Keeping the task state, filters and visible counts synchronized after every user action required a consistent render/save flow.

What I learned

I strengthened DOM state management, data persistence and small-product UX decisions.
