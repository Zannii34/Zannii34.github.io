Weather Dashboard

A browser weather dashboard powered by Open-Meteo, with city search, device geolocation and a five-day forecast.

Open DemoView CodeAll Projects

The problem

The app needed to provide useful weather information without requiring users to configure a private API key.

My solution

I used Open-Meteo geocoding and forecast endpoints to provide city search and current conditions, with browser geolocation as an optional shortcut.

Key features

  • City geocoding search
  • Current temperature, humidity, wind and apparent temperature
  • Five-day forecast
  • Use My Location button
  • Network and geolocation error messages

Challenge / technical decision

Location permissions and network failures vary by browser, so the UI provides fallback messaging and keeps city search available.

What I learned

This project reinforced API composition, geolocation permissions, async error handling and date/forecast presentation.
