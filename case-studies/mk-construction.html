The problem

The project needed to feel like a credible construction company website rather than a generic template, while keeping enquiries and service information easy to find.

My solution

I rebuilt the presentation around a stronger visual identity, dedicated MK branding, local project photography, responsive navigation, service cards, a project gallery and a simple enquiry interaction.

Key features

  • Responsive navigation and page sections
  • Custom MK Construction logo and visual identity
  • Locally bundled construction imagery with attribution notes
  • Services, project gallery and enquiry call-to-action
  • Mobile-first layout refinements

Challenge / technical decision

Balancing strong photography with readable text and fast loading. I kept the images local, used overlays for contrast and limited the number of large assets.

What I learned

This project strengthened my understanding of business-focused information architecture, responsive CSS and visual consistency.
